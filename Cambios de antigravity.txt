1. Lee las entradas en orden cronologico (de arriba hacia abajo en la seccion "HISTORIAL DE CAMBIOS").

   - **ID y Fecha/Hora**: Identificador unico del cambio.
   - **Objetivo / Resumen**: Que problema resuelve o que funcion agrega.
   - **Archivos Afectados**: Rutas relativas desde la raiz del proyecto (`FOLIO-PDF-ENTERPRISE`).
   - **Instrucciones Exactas de Implementacion (Bloques SEARCH / REPLACE)**:
     - Ubica en cada archivo el bloque `<<< SEARCH` (incluyendo lineas de contexto) y reemplazalo exactamente por el bloque `=== REPLACE`.
   - **Comandos / Verificacion**: Pruebas o comandos que debes ejecutar para validar que la implementacion quedo identica.
3. Respeta siempre las reglas arquitectonicas de EVA PDF Enterprise:
   - Privacidad por diseno (borrado temporal en `runtime/`, sin guardar documentos en SQLite).
   - Aislamiento por subprocesos (`worker.py` / `ProcessTree`).
   - Compatibilidad de `CLIENT_BUILD` en `server.py` cuando cambien contratos HTTP/JS.

  ================================================================================

  Sigue estos pasos desde una terminal PowerShell ubicada en la raiz del proyecto

  1. PREPARACION UNICA (PRIMERA VEZ EN EL EQUIPO)

  Ejecuta los siguientes comandos en orden dentro de PowerShell:

  # 1. Crear el entorno virtual .venv
  python -m venv .venv

  # 2. Actualizar pip e instalar las dependencias del proyecto
  .\.venv\Scripts\python.exe -m pip install --upgrade pip
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt

  # 3. (Opcional pero recomendado) Descargar los modelos locales de OCR (espanol e ingles)
  powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\install-ocr.ps1

  # 4. (Opcional) Calibrar los motores segun el hardware de tu equipo
  .\.venv\Scripts\python.exe .\server.py --calibrate

  NOTA SOBRE OFFICE A PDF:
  Si deseas usar la herramienta "Office a PDF", necesitas tener instalado
  LibreOffice en Windows (el motor lo detecta automaticamente en
  C:\Program Files\LibreOffice\program\soffice.com).

  --------------------------------------------------------------------------------
  2. INICIAR EL SERVIDOR LOCALMENTE
  --------------------------------------------------------------------------------
  Una vez creado el entorno .venv, tienes dos formas de arrancarlo:

  OPCION A: Con doble clic (Atajo incluido)
  - Modo solo local (este equipo): Haz doble clic sobre "servidor local.bat"
    (ejecuta .\deploy\run-lan.ps1 -LocalOnly).
  - Modo red local (LAN): Haz doble clic sobre "servidor para LAN.bat"
    (ejecuta .\deploy\run-lan.ps1).

  OPCION B: Desde PowerShell
  - Modo solo local:
    .\.venv\Scripts\python.exe .\server.py --host 127.0.0.1 --port 8090
  - Modo red local (LAN):
    .\.venv\Scripts\python.exe .\server.py --host 0.0.0.0 --port 8090

  --------------------------------------------------------------------------------
  3. ABRIR EN EL NAVEGADOR
  --------------------------------------------------------------------------------
  Con la consola del servidor abierta, entra en tu navegador a:
  - Aplicacion principal:          http://127.0.0.1:8090/
  - Editor PDF estilo Acrobat:     http://127.0.0.1:8090/editor
  - Estado de salud (JSON):        http://127.0.0.1:8090/health
