EVA PDF ENTERPRISE - INSTALADOR OFFLINE PARA WINDOWS x64
===============================================

INSTALAR (sin Internet y sin permisos de administrador)
  1. Extraiga TODO el ZIP en una carpeta (clic derecho > Extraer todo).
     No ejecute el instalador desde dentro del ZIP.
  2. Doble clic en  INSTALAR.bat
     - Verifica la integridad (SHA256) de todos los archivos.
     - Copia EVA PDF Enterprise a  %LOCALAPPDATA%\EVA-PDF-Enterprise
     - Calibra los motores PDF/OCR para el hardware de este equipo.
     - Crea accesos directos en el Escritorio y en Inicio > EVA PDF Enterprise.
  3. Abra el acceso directo "EVA PDF Enterprise". El navegador se abre en
     http://127.0.0.1:8090/  (si el puerto esta ocupado usa 8091-8099).

  Carpeta distinta:  INSTALAR.bat -InstallDir "D:\Apps\EVA-PDF-Enterprise"
  Sin accesos:       INSTALAR.bat -NoShortcuts

USO
  - "EVA PDF Enterprise": solo este equipo (127.0.0.1). No abre puertos de red.
  - "EVA PDF Enterprise (compartir en LAN)": otros equipos entran por la IP de este
    equipo; requiere la regla de firewall (ver COMPLEMENTOS_ADICIONALES.txt).
  - El servidor corre en la ventana minimizada de EVA-PDF.exe. Cerrarla lo detiene.

ACTUALIZAR
  Ejecute INSTALAR.bat de la nueva version con EVA PDF Enterprise cerrado. Se conservan
  config\site_config.json y la carpeta instance (configuracion y datos).

DESINSTALAR
  Inicio > EVA PDF Enterprise > "Desinstalar EVA PDF Enterprise" (pregunta si conservar datos).

COMPLEMENTOS
  Lea COMPLEMENTOS_ADICIONALES.txt: LibreOffice (Office a PDF), firewall LAN,
  controladores de escaner y soluciones a errores frecuentes.

CONTENIDO DEL PAQUETE
  INSTALAR.bat / INSTALAR.ps1      Instalador.
  EVA-PDF\                         Programa (EVA-PDF.exe + librerias + modelos OCR).
  app\                             Lanzador, desinstalador y herramientas.
  PAQUETE-INFO.txt                 Version, build y huellas SHA256.
